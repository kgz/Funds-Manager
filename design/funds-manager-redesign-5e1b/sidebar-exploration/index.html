Final recommendation

Use progressive groups with command actions.

This combination preserves the complete, readable navigation for recognition and discovery, while giving frequent users a faster path to both destinations and direct actions. “Upload a statement” can open an in-place workflow instead of forcing a page transition. It adds more implementation work than disclosure alone, but best supports a self-hosted personal-finance app where users alternate between browsing, checking, and importing.
