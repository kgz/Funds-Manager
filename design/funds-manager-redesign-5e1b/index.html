What stayed the same (behaviour)

  • No login / auth — local self-hosted SPA assumption
  • Sidebar: progressive groups + Find or do anything command (⌘K) — see sidebar-exploration/ for IA study
  • Sidebar brand FUNDS and exact nav labels + grouping (Overview / Cash flow / Net worth / Data & setup)
  • Attention badges on Transactions and Planned spending
  • Dashboard title “Spending & Income Overview”, account + period filters, four KPIs with vs-prior deltas, cash-flow bars, category donuts (slice → transactions), balance / net-worth charts
  • Transactions filters, recategorize / new category, table columns, pagination
  • Statements PDF upload, list, missing-period alerts
  • Categories tree with colour, merge, reorder affordances
  • Serviceability income / repayments / living / surplus + stress scenario

What changed (visual)

  • Removed dark glassmorphism and purple (#a287cd) active-nav glow
  • Bound modern-minimal light paper tokens (oklch neutrals + single blue accent)
  • IBM Plex Sans + IBM Plex Mono (tabular money) — not Inter / system-only UI
  • Hairline borders, flat surfaces, KPI strips without card stack noise
  • Accent reserved for active nav + sparse chart secondary series
  • Shared chrome in css/shared.css + js/shared.js for React+Tailwind porting
