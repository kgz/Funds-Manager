# Getting started

Funds Manager is a self-hosted personal finance app: Rust/Actix API, React UI, PostgreSQL.

**There is no authentication** — personal use on your own machine. Do not expose it to the internet without your own protections.

## Install paths

| Path | Doc |
|------|-----|
| Local from source | [Local development](./local-development) |
| Docker | [Docker](./docker) |
| Releases / building | [docs/building.md](https://github.com/kgz/Funds-Manager/blob/main/docs/building.md) in the repo |

## What you get

- Import bank statement PDFs
- Categorise transactions and track spending
- Planning for cashflow and loan events
- Assets, liabilities, predictions, report snapshots

Not financial advice.
