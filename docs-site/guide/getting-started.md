# Getting started

Funds Manager is a self-hosted personal finance app for your household. Import bank statements, categorise spending, plan upcoming money moves, and track net worth on your own machine.

**There is no login.** Anyone who can reach the app can see your data. Keep it on localhost or a private network.

## Pick how you want to run it

| I want to... | Guide |
|--------------|--------|
| Try it quickly with Docker | [Run with Docker](./docker) |
| Develop or build from the source repo | [Run from a git clone](./local-development) |

## After it's running

1. Open the app in your browser.
2. Go to **Statements** and upload a bank PDF (or explore with a demo database if you cloned the repo).
3. Browse **Transactions**, **Planning**, **Accounts**, and the rest from the sidebar.

How to use the app: [User guide](/user-guide/).
