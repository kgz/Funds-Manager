# User guide

How to use Funds Manager day to day. Each page walks through part of the app with screenshots.

To install or run the app, start with the [Guide](/guide/getting-started).

| Topic | What you'll learn |
|-------|-------------------|
| [Dashboard](./dashboard) | KPIs, charts, and net worth at a glance |
| [Breakdown](./breakdown) | Spend and income by category for a period |
| [Future predictions](./predictions) | Projected balances with plans, scenarios, and goals |
| [Transactions](./transactions) | Review, categorise, transfers, and plan links |
| [Income](./income) | Detected salary and package figures for brokers |
| [Living expenses](./living-expenses) | HEM-style monthly averages and category mapping |
| [Serviceability](./serviceability) | Monthly surplus from income, repayments, and living |
| [Report snapshots](./report-snapshots) | Freeze figures for a broker pack |
| [Repeat payments](./repeat-payments) | Recurring debits and credits from statements |
| [Planning](./planning) | Upcoming spends, income, redraws, and loan changes |
| [Accounts](./accounts) | Bank accounts from statements and display names |
| [Assets](./assets) | Property, super, and other valuations for net worth |
| [Liabilities](./liabilities) | Loans and debts with balance history |
| [Statements](./statements) | Import PDFs and track missing periods |
| [Categories](./categories) | Category tree used across transactions and reports |
| [Settings](./settings) | Database connection and migrations |
